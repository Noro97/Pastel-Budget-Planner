## 2024-05-24 - Inline Objects Triggering O(N) Deep Checks in Effects
**Learning:** In React, passing inline objects as props (like `stats={{ balance }}` in `App.tsx`) causes the object reference to change on every render. If child components or hooks (`useGamification`) use `JSON.stringify` on these dependencies for deep comparison to avoid unnecessary recalculations, it creates a hidden O(N) bottleneck. This is because `JSON.stringify` is executed on *every single parent render*, negating the performance benefits of memoization and causing severe frame drops when dealing with large datasets (e.g. `transactions`).
**Action:** Replace `JSON.stringify` dependency checks inside effects with O(1) primitive checks (e.g., comparing `stats.balance` directly) and reference equality checks (`transactions === prevTransactionsRef.current`) when the parent manages state immutably.
